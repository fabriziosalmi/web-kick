# Security Policy

MADKICK is a fully client-side, static web page. It has no backend, no
authentication, no data collection, and no secrets. It plays a bundled audio
file and renders visuals locally in the browser. The practical security
surface is therefore small.

## Supported versions

The latest release on `main` is the only supported version.

## Reporting a vulnerability

If you find a security issue (for example, an XSS vector, a supply-chain
concern, or unsafe handling of any future user input), please report it
privately rather than opening a public issue:

- **Preferred:** GitHub private vulnerability reporting
  ([Security → Report a vulnerability](https://github.com/fabriziosalmi/web-kick/security/advisories/new))
- **Email:** fabrizio.salmi@gmail.com

Please include steps to reproduce and, where possible, a proof of concept.
You can expect an acknowledgement within a few days. Thanks for helping keep
the project safe.
